Testing shouldn't require wandering through complex and bloated APIs. Originally released 9 years ago, bejs has been revived to give JS devs a straightforward, ultra-clean assertion framework.

### Zero Frills: Simple, human-readable assertions.

### Mocha Ready: Drop it straight into your existing setup.

### Lightweight: Fast to install, zero clutter.

example code (WIP):

const be = require('bejs');

// 1. Classic Clean Assertions
be.ok(be.a.string('javascript')); // true
be.err(be.a.number('not a number')); // passes effortlessly
